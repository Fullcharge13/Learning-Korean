# 실기기 확인 목록 — 獬豸老师教韩语 v0.1 (아이폰 · 아이패드 사파리)

개발 환경에는 사파리 엔진(WebKit)과 실제 기기가 없어서, 아래 항목은 **직접 아이폰과 아이패드에서 확인**해 주셔야 해요. 화면 시험은 Chromium에 아이폰·아이패드 화면 크기만 입혀서 했어요.

## 준비

1. `python3 build.py`로 만든 `dist/` 폴더를 HTTPS 웹 공간(GitHub Pages 등)에 올려요.
2. **사파리**로 그 주소를 열어요(다른 앱 안의 브라우저 말고).

## 확인 항목

| # | 확인할 것 | 어떻게 | 정상이면 |
|---|---|---|---|
| 1 | 첫 화면 | 주소를 열기 | 2초 안쪽에 「안녕!」 해치와 「开始」 |
| 2 | 아이패드 크기 | 아이패드에서 세로·가로로 돌려 홈·레슨·보관함 | 글자와 카드가 아이폰보다 크게(1.3배), 가로 스크롤 없음, 가로 모드에선 양옆에 여백 |
| 3 | 중국어 글꼴 | 아무 화면 | 간체 글자가 깨지지 않고, 한국어 단어도 제대로 보임 |
| 4 | 카드만으로 풀기 | 1-1 레슨 끝까지 | 키보드가 한 번도 뜨지 않음 |
| 5 | 설치 안내(한 번만) | 첫 레슨을 끝내고, 하나 더 끝내기 | 첫 레슨 뒤에만 「添加到主屏幕」 안내 |
| 6 | 홈 화면 추가와 아이콘 | 공유 → 「添加到主屏幕」 | 해치 얼굴 아이콘과 「獬豸韩语」 이름, 주소창 없이 열림 |
| 7 | 오프라인 | 6번 뒤 인터넷이 될 때 한 번 열고, 비행기 모드로 다시 열기 | 홈과 레슨이 열리고, 설정에 「离线准备完成」 |
| 8 | 소리 | 무음 스위치 켠 채/끈 채 정답 | 무음이면 소리 없음 |
| 9 | 다이내믹 아일랜드·홈 막대 | 홈 화면 앱으로 홈·레슨·완료 화면 | 글자·버튼이 가려지지 않음 |
| 10 | 존재하는 리아와 파이썬 진도 | 같은 아이폰에서 리아와 파이썬을 쓰고 있었다면 두 앱을 번갈아 열기 | 두 앱의 XP·진도·이어 하기가 서로 섞이지 않음 |
| 11 | 저장 내보내기·가져오기 | 设置 → 导出存档 → 导入存档 | `haechi-korean-save-날짜.json`이 받아지고, 가져온 뒤 XP·연속 기록·물건 그대로 |
| 12 | 7일 저장 규칙 | (안내) 홈 화면에 추가하지 않은 사이트는 7일 방문이 없으면 저장이 지워질 수 있음 | 홈 화면 앱으로 쓰거나 11번으로 백업 |
| 13 | 번체(대만) 자동 열기 | 아이폰 설정 → 언어를 「繁體中文（台灣）」으로 두고 앱 주소 열기 | `…/zh-hant/`로 넘어가고 「開始第一課」처럼 번체로 보임 |
| 14 | 홈 화면 앱에서 글자판 바꾸기 | 홈 화면 앱 → 設定 → 「繁體」/「简体」, 바꾼 직후 인터넷이 될 때 한 번 열기 | 진도 그대로, 다음에 열어도 고른 글자판, 그 뒤 비행기 모드에서도 열림 |
