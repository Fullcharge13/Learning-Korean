# 해치와 한국어 v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 리아와 파이썬 v0.7.2를 복사해 줄여서, 중국어 사용자가 《延世韩国语》 1권 단어를 카드 터치만으로 익히는 「해치와 한국어」 웹앱을 만든다.

**Architecture:** 화면·규칙 코드는 참고 앱 그대로 두고 Python 실행·코드 입력을 걷어낸다. 레슨 표(`data/lessons/chN.js`)는 손으로 쓰지 않고 `tools/make_lessons.py`가 단어 CSV + 검토 CSV에서 만든다. 해치·물건 그림은 참고 시트를 잘라 만든 PNG.

**Tech Stack:** 바닐라 JS(ES 모듈) + esbuild 묶기, Node `node --test`, Python 3 빌드 도구(`build.py`, `tools/*.py`), Playwright(Chromium) 화면 시험, `opencc`(pip, 빌드·시험 때만), Pillow(그림 자르기).

**Spec:** `docs/superpowers/specs/2026-11-01-해치-한국어-설계.md`

## Global Constraints

- 바탕 코드: `Fullcharge13/Learning-Python` 커밋 `a7835a54821a4797db726376477ced429faad690`.
- 단어 자료: `Amulopapa67/open-yonsei-korean-vocabulary` `data/csv/vol-01.csv`(1,064개). 원본은 고치지 않는다.

- 장 = 1권 과 10개, 제목 「第N课」. 장마다 마지막에 장 평가(`isExam: true`).
- 음절 카드: **2~5음절**, 띄어쓰기 있는 단어 제외.
- 기기: 아이폰·아이패드. 폭 700px 이상이면 `html { zoom: 1.3 }` (미디어 쿼리 하나, 그 밖의 아이패드 전용 배치 없음).
- 화면 중국어는 모두 简体字. 해치 이름: 화면 「獬豸老师」, 설명 「해치(獬豸)」.
- 저장 키: `"haechi-korean.save"` (리아 키 `"ria-python.save"`를 읽거나 지우지 않음).
- 단어 데이터와 그로부터 만든 파일(`data/zh-review.csv`, `data/lessons/*`, `vendor/open-yonsei/*`)은 CC BY-SA 3.0, 출처 표시. 코드는 MIT.

## Review Focus

1. **긴 중국어 뜻이 보기 카드를 넘침** (예: 씨 = 「小姐，先生（用于姓之后，表示尊敬）」) → 아이폰 폭에서 줄바꿈되고 가로 넘침 없음. 시험: Task 9 Step 1 `flow.py` 「가장 긴 뜻 레슨」 순회.
2. **화면에 같은 글자로 보이는 보기 두 개**(서로 다른 단어인데 뜻이 같음) → 정답이 두 개처럼 보이면 안 됨. 시험: Task 5 Step 1 `test_options_distinct_text`.
3. **리아 앱 저장이 같은 주소에 있음** → 해치 앱은 새로 시작하고 리아 저장은 그대로. 시험: Task 1 Step 1 `save keeps ria key untouched`.
4. **혼종어 한자 대응이 틀림**(공부하다 = 工夫+하다처럼 한자 수 ≠ 음절 수) → 대응 해설 없음. 시험: Task 4 Step 1 `test_no_hanja_note_when_counts_differ`.
5. **표현·띄어쓰기 단어가 음절 카드로 나옴**(예: 「만나서 반갑습니다」) → 음절 카드 문제가 만들어지지 않음. 시험: Task 4 Step 1 `test_order_excludes_spaces`.
