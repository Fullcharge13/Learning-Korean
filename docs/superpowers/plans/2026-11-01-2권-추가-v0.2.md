# 2권 추가 v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 《延世韩国语》 2권 단어 877개를 1권 뒤 11~20장으로 이어 붙인다.

**Architecture:** 화면 코드는 바꾸지 않는다. 레슨 생성 도구가 두 권을 읽어 앱 장 id = (권−1)×10+과로 장 파일 20개를 만들고, 검토 표에 2권 low 단어를 더한다. 문구 몇 줄과 시험만 고친다.

**Tech Stack:** v0.1과 같음(바닐라 JS, Node 시험, Python 도구, opencc, Playwright).

**Spec:** `docs/superpowers/specs/2026-11-01-2권-추가-설계.md` (바탕: `docs/superpowers/specs/2026-11-01-해치-한국어-설계.md`)

## Global Constraints

- 앱 장 id = (권 − 1) × 10 + 과. 1권 레슨 id·장 제목은 바뀌지 않음.
- 2권 장 제목 「第二册 第N课」, 장 평가 제목 「第二册 第N课 测验」, 레슨 id 「(10+N)-k」.
- 오답 후보는 같은 앱 장 안에서만. 나머지 규칙(8개씩·꼬리 4개 이하·문제 3종·같은 뜻 제외·이해도 확인)은 v0.1 그대로.
- 겹치는 단어 87개는 2권에도 그대로 출제.
- low 검토 결과는 `data/zh-review.csv` 한 파일에 이어서. 데이터 라이선스 CC BY-SA 3.0.
- 커밋 메시지 끝: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` 와 `Claude-Session: https://claude.ai/code/session_01LbVuTL42jrrcUZwHJ2FNRK`.

## Review Focus

1. **1권 진도 저장이 2권으로 이어짐**(10과 장 평가 완료 → 11-1 열림, 현재 레슨이 11-1) → Task 3 Step 1 `test_vol2_opens_after_vol1`.
2. **1권 단어가 2권 오답으로 섞임**(장 밖 후보) → Task 2 Step 1 `test_distractors_stay_in_app_chapter`.
3. **같은 한국어가 두 권에 있을 때 concept 이름·복습이 섞임** → Task 2 Step 1 `test_main_writes_concept_names`에 2권 id 확인 추가.
4. **배포 크기**(장 파일 20개, index.html 레슨 목록 커짐) → Task 3 Step 4 `build_test.py`(700KB 상한).
5. **2권에 생긴 같은 뜻 쌍**(정답이 둘로 보임) → Task 2 Step 4 `tests/content.py`(이미 있는 검사, 20장 전체).
