# 해치와 한국어 — 설계서 (v0.1)

- 날짜: 2026-11-01
- 바탕 코드: `Fullcharge13/Learning-Python` (리아와 파이썬 v0.7.2, 커밋 `a7835a5`) — 본인 레포, 복사해서 줄인다
- 단어 자료: `Amulopapa67/open-yonsei-korean-vocabulary` 《延世韩国语》 1권 CSV (`data/csv/vol-01.csv`, 1,064개)
- 참고 그림: `docs/img/ref/haechi-sheet.jpg`(해치 14컷), `docs/img/ref/items-sheet.jpg`(전통 물건 15컷)

## 1. 의도

중국어(简体)를 쓰는 지인이 휴대폰 브라우저에서 하루 5~10분, 《延世韩国语》 1권 단어를 **카드만 눌러서**(타이핑·듣기 없음) 익히는 듀오링고식 웹앱. 선생님은 해치(獬豸). 무료 공개, 서버 없음.

성공 기준:
1. 1권 단어 중 보류가 아닌 단어가 모두 어느 레슨엔가 한 번 이상 나온다.
2. 모든 문제는 터치로만 풀린다(입력창 0개, 음성 0개).
3. 앱 화면에 보이는 중국어는 모두 简体字다.
4. 참고 앱의 진도·연속 기록·퀘스트·배지·보관함·오프라인이 그대로 동작한다.

범위 밖(이번 판에서 하지 않음): 2~6권, 예문·문법 설명, 듣기·발음, 한글 자모 강좌, 심화 레슨, 계정·서버.

## 3. 레슨 만들기 (데이터 흐름)

```
vocab/data/csv/vol-01.csv ─┐
data/zh-review.csv ────────┼─> tools/make_lessons.py ─> data/lessons/ch1.js … ch10.js ─> build.py ─> dist/
                           ┘   (빌드 때 한 번, 결과를 커밋)
```

- 원본 CSV는 `vendor/open-yonsei/vol-01.csv`로 복사해 둔다(출처·라이선스 파일 함께). 원본은 고치지 않는다.
- `data/zh-review.csv`(§4)가 원본 `chinese` 칸을 덮어쓴다. 판정이 `hold`인 단어는 레슨에서 뺀다.
- **장** = 1권의 과(chapter) 10개. 장 제목은 「第N课」.
- **레슨** = 단원(unit) 하나의 단어를 `sequence` 순서로 **8개씩** 끊은 묶음. 남는 단어가 4개 이하면 앞 레슨에 붙인다. 각 장 마지막에 장 평가 레슨 1개(그 장 단어에서 뽑음, `isExam: true`).
- 레슨 하나의 모양(기존 레슨 표 형식 그대로):
  - `cards`: 새 단어 카드 2~3장. 카드마다 단어 3~4개를 「한국어 — 中文」로 보여 주고, 한자어는 한자 표기를 덧붙인다.
  - `items`: 터치 문제 6개(장 평가 8개) + `check` 1개. `write` 없음.
  - `id`: 「1-3」처럼 장-순번. `concept`: 단어의 `entry_id`.
- 같은 입력이면 같은 출력(시드 = `entry_id`)이어서 다시 만들어도 레슨이 바뀌지 않는다.

## 4. 문제 3종

모두 기존 `choice`·`order` 화면을 쓴다. 새 문제 종류를 만들지 않는다.

| 종류 | 기존 type | 문제 | 보기 |
|---|---|---|---|
| 韩→中 | choice | 「친구」是什么意思？ | 중국어 뜻 4개 |
| 中→韩 | choice | 「朋友」用韩语怎么说？ | 한국어 4개. 한자어면 해설에 「親舊 → 亲旧 = 친·구」처럼 음절 대응 |
| 음절 카드 | order | 按顺序点音节：「图书馆」 | 음절 카드(`lines` = 음절, 정답 순서로 저장, 화면이 섞음). 2~5음절 단어만, 띄어쓰기 있는 표현 제외 |

- 오답 보기: 같은 장·같은 품사(`pos`)에서 고르고, 모자라면 같은 장 아무 품사. 정답과 중국어 뜻(또는 한국어)이 같은 단어는 보기에서 뺀다.
- `check` 문제: 그 레슨 단어 하나로 만든 韩→中.
- 한자 표기의 简体 변환: `origin_detail`(繁体)을 빌드 스크립트에서 `opencc`(pip, 빌드 때만, 앱에는 들어가지 않음)로 바꾼다. 음절 수와 한자 수가 다르면(혼종어 등) 대응 해설을 넣지 않는다.

### 4-1. low 단어 검토 (간체 뜻 확정)

- 대상: `review_status == low` 414개(표현 139개 포함). 같은 김에 전체 1,064개의 `chinese` 칸이 简体인지 기계 검사.
- 방법: Claude가 50개씩 나눠, 한국어 뜻에 맞는 자연스러운 简体 중국어인지 검토한다(이 환경에 중한·한중 사전 스킬은 없음).
- 결과: `data/zh-review.csv` — 칸 `entry_id, korean, chinese_orig, chinese_new, verdict(ok|fix|hold), note`. `ok`면 그대로, `fix`면 새 뜻, `hold`면 레슨에서 제외.
- `hold` 목록은 사용자에게 보여 주고, 중국어를 아는 지인 확인을 권한다.
- 라이선스: 고친 뜻은 원본 자료의 2차 저작물이므로 `data/zh-review.csv`와 생성된 레슨 표도 CC BY-SA 3.0. 앱 설정 화면과 README에 출처 표시.

## 7. 화면 언어

- 모든 화면 글자, 대사(`data/lines.js`), 퀘스트, 배지, 설치 안내를 简体中文으로 바꾼다. 한국어 단어와 물건 이름의 한국어 부분만 한글.
- 말투: 친절한 선생님, 짧은 문장. 오답은 꾸짖지 않는다.

## 8. 오류 처리

- 레슨 생성 스크립트: 보기 4개를 못 채우는 단어, 음절 수가 범위 밖인 단어는 그 문제 종류에서만 빼고 다른 종류로 대신한다. 레슨 하나의 문제가 4개 미만이 되면 실패로 멈춘다(조용히 빈 레슨을 만들지 않음).
- `zh-review.csv`에 없는 `low` 단어가 있으면 생성 스크립트가 실패로 멈춘다(검토 누락 방지).
- 그림 파일이 없으면 빌드가 실패한다.
- 저장·불러오기 오류 처리는 참고 앱의 것을 그대로 둔다.

## 10. 알려진 한계

- 단어 뜻 검토는 사람 검수만큼 정확하지 않다.
