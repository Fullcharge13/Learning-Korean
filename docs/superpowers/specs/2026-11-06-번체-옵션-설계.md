# 해치와 한국어 — 뜻 재검수 반영 + 번체(대만) 옵션 설계서 (v0.3)

- 날짜: 2026-11-06
- 바탕: v0.1 설계서 `2026-11-01-해치-한국어-설계.md`, v0.2 설계서 `2026-11-01-2권-추가-설계.md` (규칙은 그대로, 이 문서는 바뀌는 점만)
- 순서: **1부(뜻 재검수 반영)를 먼저 끝내고** 2부(번체 옵션)를 한다. 번체판은 고친 뜻을 변환한다.

## 1. 의도

- 1부: 1~20장 재검수(2026-11-06)에서 나온 뜻 수정 236개(틀린 뜻 28, 다듬기 208)를 앱에 반영한다.
- 2부: 대만 사용자가 번체(대만식 글자·단어)로 같은 앱을 쓴다. 간체판은 지금 그대로 유지한다.

성공 기준:
1. 재검수 목록의 236개 단어가 모두 고친 뜻으로 나온다. 1~20장 레슨 수(254)와 단어 수(1,941)는 그대로.
2. 휴대폰 언어가 번체(zh-TW·zh-HK·zh-Hant)면 처음부터 번체판, 아니면 간체판으로 열린다.
3. 설정의 「简体 | 繁體」로 언제든 바꿀 수 있고, 고른 쪽을 기억하며, 진도는 두 판이 같다.
4. 번체판 화면·단어·대사·해설에 간체 전용 글자가 남지 않는다. 한국어·코드는 한 글자도 바뀌지 않는다.
5. 두 판 모두 오프라인으로 열리고, 서로의 오프라인 저장본을 지우지 않는다.

범위 밖: 홍콩식 번체, 번체용 별도 문구 다듬기(처음엔 자동 변환만), 언어 고르는 첫 화면, 간체·번체 외 언어, 기계번역(LibreTranslate) 연동.

## 2. 1부 — 뜻 재검수 반영

- 입력: `docs/review/2026-11-06-재검수-고칠목록.csv`(`entry_id, 한국어, 지금 뜻, 고칠 뜻, 구분, 이유`) 236행.
- `data/zh-review.csv`에 반영한다(칸은 그대로 `entry_id,korean,chinese_orig,chinese_new,verdict,note`).
  - 이미 행이 있는 단어(low 검토분·이전 수정분)는 그 행을 `fix` + 새 뜻 + note(이유)로 바꾼다.
  - 행이 없는 high 단어는 `fix` 행을 새로 더한다(v0.2의 닫히다·성함과 같은 방식).
- 원본 한국어 오타 2개(「배탈이 나가」→「배탈이 나다」, 「여해 경비」→「여행 경비」)도 고친다:
  검토 표에 `korean_new` 칸을 더하고(비어 있으면 원본 그대로), `load_words`가 채워진 값을 쓴다.
- 원본 품사 오류도 같은 방식으로 고친다: `pos_new` 칸(비어 있으면 원본). 대상: 3장 「안」(v01-c03-u02-046) 명사 → 부사.
- 「안」은 두 단어로 구분한다(사용자 지시 2026-11-06):
  - 2장 「안」(v01-c02-u03-016, 명사) = 里面 — 물건의 위치·장소. 예문 「냉장고 안에 우유가 있어요.」
  - 3장 「안」(v01-c03-u02-046, 부사) = 不，没（否定） — 말·행동의 부정. 예문 「저는 커피를 안 좋아해요.」
  - 예문은 검수표에 싣고, v0.4 빈칸 채우기의 첫 재료로 쓴다(이번 판 앱에는 예문 문제 없음).
- `python3 tools/make_lessons.py`로 20장을 다시 만든다. 레슨 id·개수는 그대로라 기존 저장은 유효하다.
  보기 4장 구성은 바뀔 수 있다(정답·진도와 무관).
- 시험:
  - `tests/test_zh_review.py`: 3장 「안」 품사가 부사, 틀린 뜻 대표 몇 개(환전=换钱；兑换外币, 대출하다=借（书）, 차(v01-c07-u04-018)=车，汽车)와 한국어 오타 2개가 최종값인지.
  - 같은 파일의 기존 검사(간체, 한글 없음, 괄호 짝)가 236개 새 뜻에도 통과.
  - 띄어쓰기로 뜻을 나눈 단어가 0개(`[한자] [한자]` 꼴 없음) — 새 검사.
  - `tests/content.py`: 20장 254레슨 OK(같은 뜻 오답·미출제 없음).

## 3. 2부 — 번체 옵션

### 3.1 화면 흐름

- 처음 열 때: 기억된 선택이 없으면 휴대폰 언어(`navigator.languages`)가 `zh-TW`·`zh-HK`·`zh-MO`·`zh-Hant…`이면 번체, 그 밖은 간체.
- 설정 화면에 「文字 简体 | 繁體」 두 칸 버튼. 지금 판이 눌린 상태. 다른 쪽을 누르면 선택을 기억하고 그 판을 연다.
- 기억된 선택이 휴대폰 언어보다 우선.
- 진도 저장(`haechi-korean.save` 등)은 두 판이 같은 칸을 쓴다. 사용자가 입력한 이름은 변환하지 않는다.
- 주소: 간체 `…/Learning-Korean/`(그대로), 번체 `…/Learning-Korean/zh-hant/`.

### 3.2 구조

- 빌드: `build.py`가 간체판을 `dist/`에 만든 뒤, 그 결과 중 `index.html`·`lessons/*.json`·`manifest.webmanifest`·`sw.js`·`licenses.txt`를
  OpenCC `s2twp`(대만식 글자+단어)로 변환해 `dist/zh-hant/`에 쓴다. 그림·아이콘은 복사하지 않고 `../img/`·`../icons/`를 가리킨다.
- 변환 뒤 번체판에만 바꾸는 것: `<html lang="zh-Hant">`, 오프라인 저장본 접두 `haechi-hant-game-`, 그림·아이콘 경로.
- 고칠 말 표: `data/zh-hant-overrides.csv`(`from,to` 두 칸, 처음엔 머리줄만). 변환 뒤 결과에서 `from`을 `to`로 바꾼다.
- 언어 고르기: `src/lang.js`
  - `pickLang({ saved, languages }) -> "hans" | "hant"` — 순수 함수(시험 대상).
  - `src/index.html` 머리의 짧은 인라인 코드가 앱보다 먼저 판을 확인하고, 다르면 `location.replace`로 다른 판에 간다(간체가 깜빡 보이지 않게).
  - 기억 칸: `localStorage["haechi-korean.lang"]` = `"hans"` | `"hant"`. 읽기·쓰기 오류는 무시하고 지금 판을 쓴다.
  - 저장 내보내기·가져오기(`haechi-korean.save`)에는 들어가지 않는다.
- 오프라인: `sw.js`의 옛 저장본 지우기를 `key.startsWith("haechi-")`에서 **자기 판 접두**(`haechi-game-` / `haechi-hant-game-`)로 좁힌다.
  두 판은 범위가 `/`와 `/zh-hant/`로 달라 서비스 작업자가 따로 돈다.
- 바꾸지 않는 것: 레슨 생성 도구, 화면 코드의 간체 문구(문구는 간체 한 곳만 고치면 번체가 따라옴), 자동 배포(`build.py` 한 번).

### 3.3 오류 처리

- 저장 칸 접근이 막히면(개인정보 보호 모드) 휴대폰 언어로만 고르고, 전환 버튼은 그 판을 열기만 한다(기억 안 됨).
- 번체판을 처음 열 때 오프라인이면 아직 저장본이 없어 열리지 않는다 → 기기 점검표에 "전환 직후 온라인에서 한 번 열기" 안내.

## 4. 시험

1. `tests/build_test.py`
   - `dist/zh-hant/`에 index.html, 장 파일 20개, manifest, sw.js가 있다.
   - 번체판 화면 글자·장 파일에 간체 전용 글자가 없다(OpenCC로 `s2t` 변환 시 바뀌는 글자 없음).
   - 두 판에서 한자(CJK)를 지운 나머지가 같다(경로·`lang`·저장본 접두 차이만 허용).
   - sw.js 저장본 접두가 각각 `haechi-game-`·`haechi-hant-game-`이고, 지우기 조건이 자기 접두만 본다.
   - 번체 index.html ≤ 700KB.
   - 고칠 말 표에 시험용 줄을 넣으면 결과에 반영된다.
2. `npm test`: `pickLang` — 선택 없음 + zh-TW/zh-HK/zh-Hant-TW → hant, zh-CN/ko/en → hans, 선택이 있으면 그 값 우선, 이상한 값은 무시.
3. `tests/flow.py`
   - 브라우저 언어 zh-TW로 루트를 열면 `/zh-hant/`로 넘어가고 홈에 번체 글자(「繼續學習」)가 보인다.
   - 설정에서 「简体」 → 간체판, 다시 열어도 간체 유지. XP·현재 레슨 그대로.
   - 번체판에서 레슨 하나를 끝까지 풀 수 있다.
   - 번체판도 오프라인으로 다시 열린다.
4. `docs/device-checklist.md`: 아이폰 언어를 대만 중국어로 두고 열기, 홈 화면 앱에서 전환.

## 5. 위험

- 자동 변환이라 대만에서 덜 쓰는 표현이 남을 수 있다(예: 公交車, 대만은 公車) → 고칠 말 표로 보완.
- 뜻 236개와 번체 변환 모두 원어민 검수가 아니다.
- 휴대폰 언어가 영어인 대만 사용자는 간체로 열린다 → 번체 주소를 직접 안내.
